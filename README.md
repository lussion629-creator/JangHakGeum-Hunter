# 장학금헌터

공공데이터와 누구나 볼 수 있는 공개 공지에서 장학금을 모아, 한곳에서 찾고 마감을 놓치지 않게 도와주는 무료 웹앱·안드로이드 앱입니다.

웹앱: https://lussion629-creator.github.io/JangHakGeum-Hunter/

## 기능

- **장학금 찾기**: 지원 종류(등록금·생활비·기숙사·학자금 대출·근로 등), 모집 상태, 지역, 운영기관으로 고르고 이름·재단·지역·학교·학과로 검색
- **내 정보 맞춤**: 학교·학과·지역·소득구간 등을 넣으면 지원 가능 / 확인 필요 / 지원 불가와 그 이유를 보여 줌 (기기 안에서만 계산)
- **학교 전용 공고**: 그 학교 학생만 지원할 수 있는 공고는 따로 모아 학교를 골라 볼 수 있음
- **알림**: 관심 장학 마감, 키워드·비슷한 장학 새 공고 알림 (안드로이드 앱)
- **마감 달력**, **관심 장학**, **숨기기**, **서류 쓰기**(추천서 부탁 메일·자기소개서 초안용 글 만들기)
- 다크 모드, 홈 화면에 추가해 앱처럼 쓰기, 인터넷이 없어도 마지막 목록 보기

## 정보를 다루는 원칙

- **공개된 정보만** 씁니다: 공공데이터포털(한국장학재단 학자금지원정보 등)과 로그인 없이 볼 수 있는 대학·재단·지자체의 공개 공지. 로그인이 필요한 포털이나 다른 장학 정보 서비스의 자료는 쓰지 않습니다.
- 공지를 읽을 때는 각 사이트의 **robots.txt** 를 지키고, 요청 사이에 쉽니다. 수집 프로그램 이름은 `ScholarshipHunterBot` 입니다.
- 공고 전문과 이미지는 다시 싣지 않고 **기간·대상·금액 같은 핵심과 출처, 원문 링크**만 보여 줍니다.
- 기관이 게재 중단을 요청하면 지체 없이 빼고 이후 수집에서도 제외합니다.

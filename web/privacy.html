← 장학금헌터

개인정보처리방침

시행일: 2026년 10월 20일

장학금헌터는 이용자의 개인정보를 수집하지 않습니다. 회원가입과 로그인이 없고, 이용자가 입력한 정보를 서버로 보내지 않습니다.

1. 이용자 기기에만 저장되는 정보

아래 정보는 맞춤 찾기·알림 기능을 위해 이용자가 직접 입력하거나 선택한 것으로, 이용자의 기기(브라우저 저장소 또는 앱 저장소)에만 저장됩니다. 운영자를 포함해 누구도 볼 수 없습니다.

  • 내 정보: 학교, 학과, 학년, 지역, 소득구간, 성적, 해당 사항(다자녀·장애 등) — 입력한 경우에만
  • 관심(별표) 장학, 숨긴 장학, 신청 상태, 서류 체크 여부, 알림 키워드
  • ‘서류 쓰기’ 화면에 적은 내용
  • 화면 설정(글자 크기, 어두운 화면 등)

기기의 ‘내 정보 초기화’를 누르거나, 브라우저 사이트 데이터를 지우거나, 앱을 삭제하면 모두 지워집니다.

2. 앱 권한

  • 인터넷: 장학 목록을 받아 오기 위해 씁니다.
  • 알림: 관심 장학 마감과 새 장학을 알리기 위해 씁니다. 거부해도 다른 기능은 쓸 수 있습니다.
  • 기기 재시작 후 실행: 다시 켠 뒤에도 알림 확인 일정을 이어 가기 위해 씁니다.

3. 제3자 제공·처리 위탁·국외 이전

개인정보를 수집하지 않으므로 제3자에게 제공하거나 처리를 위탁하지 않습니다. 다만 웹사이트와 장학 목록 파일은 GitHub Pages(GitHub, Inc., 미국)에서 제공되며, 다른 웹사이트와 마찬가지로 GitHub가 서비스 운영과 보안을 위해 접속 기록(IP 주소 등)을 처리할 수 있습니다. 이는 GitHub 개인정보 처리방침을 따릅니다. 장학금헌터는 이 기록을 받거나 이용하지 않습니다.

4. 쿠키·분석 도구·광고

쿠키, 이용 행태 분석 도구, 광고 식별자를 쓰지 않습니다.

5. 아동의 개인정보

중·고등학생도 이용할 수 있지만 개인정보를 수집하지 않으므로 법정대리인 동의 절차가 필요하지 않습니다.

6. 바깥 링크

‘공고 원문 보기’ 등은 장학 운영기관의 사이트로 연결됩니다. 연결된 사이트의 개인정보 처리는 해당 기관의 방침을 따릅니다.

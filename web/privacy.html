← 장학금헌터

개인정보처리방침

시행일: 2026년 10월 30일 (이전 방침: 2026년 10월 20일 시행)

장학금헌터 운영자는 이용자의 개인정보를 수집하지 않습니다. 회원가입과 로그인이 없고, 이용자가 입력한 정보를 서버로 보내지 않습니다.

다만 안드로이드 앱 화면 아래에는 광고가 나오며, 광고를 보여 주는 Google(애드몹)이 광고 식별자 등 아래 3·4항의 정보를 직접 수집해 처리합니다. 웹사이트에는 광고가 없습니다.

1. 이용자 기기에만 저장되는 정보

아래 정보는 맞춤 찾기·알림 기능을 위해 이용자가 직접 입력하거나 선택한 것으로, 이용자의 기기(브라우저 저장소 또는 앱 저장소)에만 저장됩니다. 운영자를 포함해 누구도 볼 수 없습니다.

  • 내 정보: 학교, 학과, 학년, 지역, 소득구간, 성적, 해당 사항(다자녀·장애 등) — 입력한 경우에만
  • 관심(별표) 장학, 숨긴 장학, 신청 상태, 서류 체크 여부, 알림 키워드
  • ‘서류 쓰기’ 화면에 적은 내용
  • 우리 학교 장학캘린더(안드로이드 앱): 이용자가 직접 학교 포털에 로그인해 저장한 장학 화면의 주소와 그 화면의 장학 목록, 학교 포털의 로그인 상태(쿠키). 아이디·비밀번호는 저장하지 않고, 본인의 신청·수혜 내역 표는 읽지 않으며, ‘연결 지우기’를 누르면 지워집니다.
  • 화면 설정(글자 크기, 어두운 화면 등)

기기의 ‘내 정보 초기화’를 누르거나, 브라우저 사이트 데이터를 지우거나, 앱을 삭제하면 모두 지워집니다.

2. 앱 권한

  • 인터넷: 장학 목록을 받아 오기 위해 씁니다.
  • 알림: 관심 장학 마감과 새 장학을 알리기 위해 씁니다. 거부해도 다른 기능은 쓸 수 있습니다.
  • 기기 재시작 후 실행: 다시 켠 뒤에도 알림 확인 일정을 이어 가기 위해 씁니다.
  • 광고 ID: 안드로이드 앱의 광고를 보여 주고 측정하기 위해 Google 애드몹이 씁니다.

3. 제3자 제공·처리 위탁·국외 이전

운영자는 개인정보를 수집하지 않으므로 제3자에게 제공하거나 처리를 위탁하지 않습니다.

광고(안드로이드 앱): 앱에 들어 있는 Google 애드몹 SDK가 아래 정보를 Google로 직접 보냅니다.

  • 받는 자: Google LLC (미국)
  • 항목: 광고 ID, IP 주소, 기기·앱 정보(기종, 운영체제, 언어, 앱 버전), 광고 노출·클릭 기록
  • 목적: 광고 제공·측정, 부정 클릭 방지
  • 일시·방법: 앱에서 광고를 불러올 때 네트워크로 전송
  • 보유 기간: Google 개인정보처리방침과 파트너 사이트·앱의 데이터 사용 방식에 따름
  • 거부 방법: 아래 4항의 광고 ID 삭제·맞춤 광고 끄기. 거부해도 앱의 다른 기능은 그대로 쓸 수 있습니다.

웹사이트·장학 목록 파일: 웹사이트와 장학 목록 파일은 GitHub Pages(GitHub, Inc., 미국)에서 제공되며, 다른 웹사이트와 마찬가지로 GitHub가 서비스 운영과 보안을 위해 접속 기록(IP 주소 등)을 처리할 수 있습니다. 이는 GitHub 개인정보 처리방침을 따릅니다. 장학금헌터는 이 기록을 받거나 이용하지 않습니다.

4. 쿠키·분석 도구·광고(행태정보)

웹사이트는 쿠키, 이용 행태 분석 도구, 광고 식별자를 쓰지 않습니다. 안드로이드 앱에서는 Google 애드몹이 광고 ID와 광고 노출·클릭 기록(행태정보)을 이용해 광고를 고를 수 있습니다. 운영자는 이 정보를 받거나 볼 수 없습니다.

맞춤 광고를 원하지 않으면 휴대폰 설정 → 개인 정보 보호(또는 Google) → 광고에서 광고 ID를 삭제하거나 재설정할 수 있습니다. 광고 ID를 지우면 맞춤이 아닌 일반 광고가 나옵니다.

5. 아동·청소년

장학금헌터는 대학생과 고등학생을 위한 서비스로, 만 14세 미만 아동을 대상으로 하지 않습니다. 운영자는 개인정보를 수집하지 않으므로 법정대리인 동의 절차가 필요하지 않습니다. 광고는 청소년이 볼 수 있는 등급(T) 이하로 제한하고, 술·도박·성인용 등 민감한 분야의 광고는 막아 둡니다.

6. 바깥 링크

‘공고 원문 보기’ 등은 장학 운영기관의 사이트로 연결됩니다. ‘구글 캘린더에 추가’·‘최신 공고 검색’은 장학 이름과 날짜만 담아 Google 화면을 열고, ‘서류 쓰기’의 AI 서비스 바로가기는 그 사이트를 열기만 합니다(입력한 내용을 함께 보내지 않습니다). 이용자가 직접 복사해 붙여 넣은 내용과 연결된 사이트에서의 개인정보 처리는 해당 서비스의 방침을 따릅니다.
